# Known limitations and roadmap

**Community developer preview:** an investigation aid, not a cleanup engine or Microsoft-supported diagnostic replacement.

## Known gaps

- Accessible published metadata only; complete unpublished state, effective history and every hidden customization are not established.
- Low-level classic sources and the virtual-layer provider vary by version/environment. Complete paging does not certify the provider's underlying completeness.
- Empty classic stacks have been observed. Parent-only unmanaged evidence remains review required, with no specific button inferred.
- Creation candidates are not confirmed creations. An underlying managed definition can be unavailable.
- Modern evidence is component-level. Formula bodies/runtime dependencies and custom-page internals are not audited.
- Origin recognizes a small set of Microsoft factory publisher IDs. Other legitimate publishers can remain Not verified.
- Some labels remain IDs/macros. Menus are not button rows; type changes, global/table shadowing and indirect runtime rules can need manual review.
- No minimal privilege role, cross-tenant compatibility matrix, performance benchmark, accessibility certification or independent architecture review is established.
- Memory grows with the scan; filtering/sorting are client-side. No persistence, resumability, global request budget or large-environment performance guarantee.
- Model-driven shells can cache old HTML. Earlier browser-automation startup failures were not conclusively resolved; test normal app launch separately from the direct resource.

## Roadmap by evidence value

1. Independent sandbox import/upgrade/uninstall and reviewer-role validation.
2. Controlled classic managed/unmanaged fixture matrix across platform versions, compared with Command Checker/exported definitions.
3. External baseline provenance/comparison before any confirmed-creation label.
4. Additional item kinds, global/table shadowing and nested-rule cases.
5. Scan timestamps, stable evidence IDs and performance/cancellation measurements.
6. Better comparison presentation and accessibility review.

These are proposals, not completed capabilities. One-click production cleanup is outside this preview.
